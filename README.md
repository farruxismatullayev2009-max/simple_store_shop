# E-commerce Store

Ecommerce Store — bu HTML, SCSS va JavaScript yordamida yaratilgan online do‘kon loyihasi. Loyihada foydalanuvchilar mahsulotlarni qidirishi, filter qilishi va mahsulot sahifalarini ko‘rishi mumkin.

## Ishlatilgan texnologiyalar

- HTML5
- SCSS (SASS)
- JavaScript
- Node.js
- Responsive Design

## Asosiy funksiyalar

- 🔍 Product Search
- 🎨 Theme Change (Dark / Light Mode)
- 📱 Responsive Design
- 🛍️ Single Product Page
- 🔐 Login Page
- 📂 Product Filter System

## Papkalar tuzilishi

```bash
styles/
sass/
singlepagestyles/
```

## Ishga tushirish

1. Loyihani yuklab oling

```bash
git clone <repository-link>
```

2. Dependencies o‘rnating

```bash
npm install
```

3. `index.html` faylini brauzerda oching

## SCSS ishlatish

SCSS fayllarni CSS ga compile qilish uchun:

```bash
npx sass sass/style.scss styles/style.css --watch
```
